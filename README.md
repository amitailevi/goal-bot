# ⚽ בוט 2 שערים

**האתר:** https://amitailevi.github.io/goal-bot/

דף אינטרנט שעוקב בזמן אמת אחרי כל משחקי הכדורגל החיים בפולימרקט, ומתריע כשקבוצה מובילה בפער של 2 שערים ומעלה (אפשר לבחור פער של 1 עד 5).
ההתראה היא צפצוף, הודעה קופצת בדסקטופ, באנר בראש הדף וכרטיס מודגש.
**הבוט רק מתריע. הוא לא קונה ולא מוכר.**

## מה רואים במסך
- **שורת מצב:** "חי" (כשהתוצאות והמחירים מחוברים), כפתור צליל (הפעלה/השתקה), בורר פער.
- **3 מספרים:** בפער 2+ · קרוב לפער (יתרון של שער אחד) · משחקים חיים.
- **כרטיס לכל משחק בפער 2+:** דגל המדינה, רמת המסגרת (ליגה ראשונה, ליגה שנייה, גביע, ליגת האלופות, הליגה האירופית, נבחרות, נשים), שם הליגה, דקה ופס התקדמות, תוצאה, **מחיר קנייה חי** לניצחון הקבוצה המובילה, השינוי מאז ההתראה, ושורת "מנצחת +X¢ (+Y%) · לא מנצחת −Z¢". לחיצה על הכרטיס פותחת את המשחק בפולימרקט.
- **"קרוב לפער":** רשימה עם מחיר חי לכל קבוצה מובילה. משחקי שוויון מוסתרים מאחורי כפתור. יש גם היסטוריית התראות.

## מאיפה הנתונים (הכל ציבורי, בלי התחברות)
| מה | מקור |
|---|---|
| תוצאות חיות | Polymarket Sports WebSocket — `wss://sports-api.polymarket.com/ws` |
| מחירים חיים | Polymarket CLOB Market WebSocket — `wss://ws-subscriptions-clob.polymarket.com/ws/market`. מנוי לטוקן "כן" של הקבוצה המובילה בכל משחק עם יתרון. מוצג ה-best ask (מחיר הקנייה הזול ביותר כרגע). |
| פרטי משחקים ושווקים | Gamma REST API: צילום מצב בטעינה (כדי לתפוס גם משחקים במחצית), ושליפה קלה לכל משחק (~20KB) כשקבוצה עולה ליתרון. |
| ליגות | `GET /sports` של Gamma (185 ליגות כדורגל) + טבלה בקוד: מדינה ורמה לכל ליגה. |

## לוגיקת ההתראה
- יש התראה כשהבוט רואה מעבר מפער קטן לפער 2+. משחק שכבר היה בפער כשהדף נטען לא מצפצף (90 השניות הראשונות הן "חימום").
- התראה אחת לכל פעם שנוצר פער: אם הפער ירד וחזר, תהיה התראה חדשה. רק תוצאה מה-WebSocket יכולה לבטל התראה, כי ה-REST מתעכב.
- חיבור מחדש אוטומטי ו-heartbeat לשני החיבורים. אם זרם המחירים שקט, הבוט קורא את ספר הפקודות ישירות בערך כל 25 שניות.
- עדכוני מחיר נצבעים במקום (ירוק אם עלה, אדום אם ירד), בלי לבנות את הדף מחדש.

## אחסון
קובץ HTML אחד (`index.html`) בלי שרת, מתארח ב-GitHub Pages. רענון לא מוחק את הבוט.

## מגבלות ידועות
- עובד רק כשהדף פתוח והמחשב ער. אין התראות לטלפון כשהמחשב כבוי.
- כרום דורש לחיצה אחת אחרי טעינה כדי להפעיל צליל.
- נתוני פולימרקט יכולים להתעכב. לפעמים המחיר זז לפני שהתוצאה מתעדכנת.
- טבלת הרמות מתוחזקת ידנית. לליגה חדשה הרמה נקבעת לפי ניחוש מהשם.
